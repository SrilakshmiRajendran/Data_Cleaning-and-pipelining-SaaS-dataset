# SaaS Data Cleaning Pipeline

📌 Project Overview

A Python-based project for cleaning, validating, analyzing, and exporting SaaS customer data.

✨ Features

Display SaaS customer records

Add new customer records with auto-increment IDs

Validate and clean customer data

Handle missing and invalid values

Remove duplicate customer records

Standardize signup dates

Calculate summary statistics

Identify low-usage customers

Extract unique plan types

Export cleaned data to CSV

Generate plan summary report

Use exception handling for file operations

🛠️ Skills & Concepts

Python

Lists, Dictionaries & Sets

Functions & Loops

Object-Oriented Programming (OOP)

Data Cleaning & Validation

Exception Handling

CSV & Text File Handling

Basic Data Analysis

📁 Output Files

saas_customers_cleaned.csv

plan_summary.txt
